# Legion Risers Plain Polo Shirt — iOS Glass E-Commerce Experience
### In Collaboration with Nexure Studios

A human-crafted, luxury fashion e-commerce web application engineered with Apple Cupertino's **iOS 18 Liquid Glass** design philosophy, featuring a **Full White Theme**, authentic **San Francisco** typography, and a cinematic 2-3 second 3D shirt unfolding opening experience.

---

## 🚀 Quick Start

To preview or run the site locally:

```bash
# 1. Install dependencies
npm install

# 2. Start the Vite dev server
npm run dev

# 3. Open in your browser
http://localhost:5173/
```

To build a production-ready release:

```bash
npm run build
npm run preview
```

## ✨ Features & Specifications

### 1. Opening 3D Shirt Unfolding Intro (2-3 Seconds)
- When opening the site, a luxury white atelier backdrop introduces the brand with the Legion Risers eagle crest.
- The garment begins in a folded boutique packaging format with an archival ribbon. Over 2.5 seconds, the sleeves unfold outwards and the body cascades down into the complete drop-shoulder silhouette before seamlessly dissolving into the live hero stage.
- Includes a clean frosted **Skip** button for immediate bypass.

### 2. Clean, Quiet Full White iOS Aesthetic
- **No Status Bar clutter**: Removed time, 5G Ultra, Wi-Fi, and battery charging indicators.
- **No sound**: Completely silent and peaceful luxury shopping experience.
- **No blinking dots**: Replaced pulsing lights with clean, static, minimal pill badges.

### 3. Corner Branding
- **Top-Left Corner**: Official **Legion Risers** insignia capsule (`assets/legion_risers_clean.png`) with "EST. 2026 • HAUTE COUTURE".
- **Top-Right Corner**: Official **Nexure Studios** partnership capsule (`assets/nexure_studios_clean.png`) with signature 4-color dots.

### 4. Interactive Color Switcher (5 Colorways)
Seamlessly switch between realistic luxury fabric colorways with preserved eagle crest embroidery:
1. **Onyx Black**: Midnight depth with contrast sterling-white eagle crest.
2. **Crimson Red**: Bold cardinal scarlet with vibrant presence.
3. **Pacific Blue**: Regal Oxford navy with tailored elegance.
4. **Alpine Green**: Subtle forest moss tone with relaxed drape.
5. **Chalk White**: Pristine alabaster cotton with stealth onyx-black eagle crest.

### 5. Smooth Scrolling & 3D Interactive Parallax
- **3D Gyro / Cursor Tilt**: Moving the cursor or tilting your mobile device realistically tilts the shirt on its glass pedestal in 3D space with dynamic cast shadows.
- **Scrollytelling Lens**: As you scroll through the page, the camera smoothly tracks between:
  - *Full Silhouette* (360 interactive view)
  - *Eagle Crest* (12,000+ micro-stitch macro view)
  - *Collar Architecture* (2-ply anti-sag ribbed necktape)
  - *Materiality* (280 GSM French Terry knit)
